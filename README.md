# Решение задачи прогнозирования стоимости жилой недвижимости на основе табличных данных.

Датасет: [House Prices: Advanced Regression Techniques (kaggle)](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data)


Краткие итоги по текущей проделанной работе:

Проведены:
- разведочный анализ данных;
- обработка пропущенных значений;
- анализ взаимосвязей между признаками и целевой переменной.

### Сравнение применения OneHotEncoder / OneHotEncoder + OrdinalEncoder
Особое внимание было уделено сравнению различных подходов к предобработке категориальных признаков: 
- простое one-hot кодирование всех признаков;
- комбинированный подход с использованием порядкового кодирования упорядоченных категориальных признаков и one-hot кодирования оставшихся.
 Для каждого варианта предобработки данных были обучены и сравнены несколько моделей машинного обучения с использованием кросс-валидации и различных метрик качества.

Результаты всех запусков были сагрегированы в одну такблицу. Результаты работы алгоритма отсортированы по метрике RMSLE – так как именно на её основе строится список лидеров на Kaggle.
